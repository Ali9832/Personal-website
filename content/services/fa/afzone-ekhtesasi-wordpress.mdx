## نشانه‌هایی که افزونه اختصاصی لازم دارید

- برای یک کار ساده، سه افزونه نصب کرده‌اید که هر کدام ده قابلیت دیگر هم می‌آورند.
- فایل `functions.php` قالب شما هزار خط شده و هیچ‌کس جرئت دست‌زدن به آن را ندارد.
- افزونه‌ای که استفاده می‌کنید نگهداری نمی‌شود و آخرین آپدیتش دو سال پیش بوده.
- نیاز شما خیلی خاص کسب‌وکار خودتان است و اصلاً محصول عمومی برایش وجود ندارد.

## کد چطور نوشته می‌شود

بدون دست‌زدن به هسته، بدون تغییر مستقیم افزونه‌های دیگر، و با هوک‌هایی که خودِ افزونه هم برای توسعه بعدی در اختیار می‌گذارد:

```php
<?php
/**
 * Plugin Name: Acme Order Router
 * Requires PHP: 8.1
 */

declare( strict_types = 1 );

add_action( 'woocommerce_checkout_create_order', 'acme_assign_warehouse', 10, 2 );

function acme_assign_warehouse( WC_Order $order, array $data ): void {
    $province = $order->get_shipping_state();
    $warehouse = acme_pick_warehouse( $province );

    // فیلتر عمومی: منطق انتخاب انبار بعداً بدون تغییر این فایل قابل بازنویسی است.
    $warehouse = apply_filters( 'acme_selected_warehouse', $warehouse, $order );

    $order->update_meta_data( '_acme_warehouse', $warehouse );
}
```

دو نکته در همین قطعه کوچک: `declare(strict_types=1)` چون تایپ ضعیف PHP منبع باگ‌های خاموش است، و `apply_filters` چون افزونه‌ای که قابل توسعه نباشد، شش ماه بعد باید بازنویسی شود.

## فعال‌سازی و مهاجرت داده

بیشتر خرابی‌های جدی افزونه‌ها موقع فعال‌سازی و آپدیت اتفاق می‌افتد. هر افزونه‌ای که می‌نویسم شماره نسخه اسکیما را نگه می‌دارد و مهاجرت‌ها را پله‌به‌پله و قابل بازگشت اجرا می‌کند — نه یک `dbDelta` که امیدوار باشیم درست کار کند.
